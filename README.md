# 🥀 Генератор гнилых высказываний

> Правда, от которой не становится легче.

Небольшой веб-генератор циничных и горьких «житейских истин». Каждая фраза собирается случайно из шаблонов. Фразы каждый раз новые, но повторы тоже возможны.

🔗 **Демо:** [screpka228.github.io/rotten-phrases-generator](https://screpka228.github.io/rotten-phrases-generator/)

---

## ✨ Возможности

- 🎲 Случайная генерация фраз из четырёх частей
- 📋 Кнопка «Копировать» для быстрой отправки в чат
- 🕘 История последних пяти фраз
- 📱 Адаптивная вёрстка: работает на телефоне и на компьютере
- 🧩 Один файл, без сборки и без зависимостей

## 🚀 Запуск

Проект не требует установки. Есть два способа:

**Онлайн.** Открой [демо](https://screpka228.github.io/rotten-phrases-generator/).

**Локально.** Скачай репозиторий и открой `index.html` в браузере:

```bash
git clone https://github.com/screpka228/rotten-phrases-generator.git
cd rotten-phrases-generator
# откройте index.html в браузере
```

## 🧠 Как устроена фраза

Фраза собирается из шаблонов:

```
[вступление] + [тема] + [сказуемое] + [концовка] (+ иногда дополнение)
```

| Часть | Пример |
| --- | --- |
| Вступление | `Опытные люди знают,` |
| Тема | `кофе` |
| Сказуемое | `требует ещё одной чашки кофе` |
| Концовка | `Вот и весь секрет.` |

Списки лежат в массивах внутри `<script>` файла `index.html`:

| Массив | Что содержит |
| --- | --- |
| `starts` | вступления |
| `subjects` | темы |
| `verbs` | сказуемые |
| `endings` | концовки |
| `extras` | дополнения, которые добавляются примерно в каждой четвёртой фразе |

## 🛠️ Свои фразы

Чтобы добавить свои варианты, просто дополни нужный массив. Например:

```js
const subjects = [
  "понедельник",
  "твоя мотивация",
  "ваш общий чат" // новый пункт
];
```

Перезагрузи страницу, и новые варианты начнут попадаться.
