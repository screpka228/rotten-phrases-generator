# Генератор гнилых высказываний

Небольшой генератор циничных «мудростей» из шаблонов. Каждая фраза собирается случайно из набора начал, тем, сказуемых и концовок.

**Демо:** https://screpka228.github.io/rotten-phrases-generator/

## Запуск локально

Файл `index.html` самодостаточный: просто открой его в браузере. Сборка не нужна.

## Как устроено

- `starts` — вступления («Опытные люди знают,»)
- `subjects` — темы («понедельник», «кофе»)
- `verbs` — сказуемые («никогда не заканчивается хорошо»)
- `endings` и `extras` — концовки и дополнения

Чтобы добавить свои фразы, просто допиши элементы в нужный массив в `<script>`.
